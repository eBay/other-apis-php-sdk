# EBay Other APIs PHP SDK

PHP SDK for miscellaneous eBay APIs.

## Covered APIs

- **EDIS Shipping API** — package management, bundles, labels, tracking
- **Identity API** — user identity lookup
- **Translation API** — text translation
- **Vero API** — VeRO (Verified Rights Owner) reporting

## Specs

OpenAPI specs are in `specs/`. Implementation not yet started.
